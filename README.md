# Data Structures and Algorithms

1. Data Structures and Algorithms

Data structures are ways of organizing and storing
data. Algorithms are step-by-step instructions
used to solve problems.

2. Linear Data Structure

A linear data structure arranges elements
sequentially, one after another.

3. One-Dimensional Array

A one-dimensional array stores multiple elements
in a single sequence.

Example:
int numbers[] = {10, 20, 30, 40, 50};

4. Big O Notation

Big O notation describes how an algorithm's
time or memory requirements grow as the
input size increases.

Examples:
- O(1) - Constant Time
- O(log n) - Logarithmic Time
- O(n) - Linear Time
- O(n²) - Quadratic Time

5. Basic Searching Algorithms

Searching algorithms are used to find a
specific element in a collection of data.

*Linear Search

Linear search checks each element one by one
until the target is found.

Time Complexity: O(n)

*Binary Search

Binary search works on sorted data by
repeatedly dividing the search range in half.

Time Complexity: O(log n)
